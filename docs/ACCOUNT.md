# 个人设置

个人设置通过 Workspace 侧栏底部、手机导航底部与 Workspace 列表页的统一账号菜单打开。账号菜单仅包含“设置”和“退出登录”；设置内统一提供个人资料、Markdown 偏好、账号安全、快捷键四个栏目，桌面侧栏和手机栏目选择保持一致；owner、editor、viewer 均可使用。桌面为 840px 弹窗，手机为全屏面板，设置期间保持当前编辑器挂载。

## 个人资料与安全

显示名称去除首尾空白，接受 1–80 个 Unicode 字符。邮箱只读。PNG/JPEG 头像限制 2MB、边长不超过 4096px，服务端居中裁切成 256px 方形并重编码为 PNG；客户端显示圆形预览。保存先处理头像，再处理姓名；部分失败保留剩余草稿。切换栏目、关闭面板前可保存、放弃或继续编辑。

资料保存后更新当前账号、成员查询和 presence/awareness 身份，不重建 Milkdown、Y.Doc 或撤销历史。头像按账号存储，读取仅限本人或共享 Workspace 的已登录成员。

修改密码要求验证当前密码，新密码沿用至少 8 字节且最多 72 字节的 bcrypt 限制。数据库事务更新密码并撤销其他会话；Realtime Hub 关闭被撤销连接，当前浏览器保持登录。密码只保存在表单内存，成功后清空。退出前发现文档或偏好未同步时先提示。

## Markdown 偏好

| 字段 | 默认值 | 范围 |
| --- | --- | --- |
| fontSize | 16 | 整数 14–22px |
| lineHeight | 1.75 | 1.5、1.75、2 |
| contentWidth | 760 | 640、760、960px |
| codeLineNumbers | true | 开关 |
| autoPair | true | 开关 |
| focusMode | false | 开关 |
| typewriterMode | false | 开关 |

偏好仅影响本人阅读与输入行为，不改变 Markdown 导出、文档标题尺寸或协作者显示。代码行距独立；正文宽度受可用空间限制。自动配对同时控制括号、引号补全、越过闭合符和空配对删除；Markdown 格式解析与转义不受影响。编辑器快捷按钮与设置面板使用同一状态源。

`PreferencesStore` 按用户 ID、字段分别缓存已确认值和待同步变更，350ms 合并 PATCH；服务器在事务内合并实际传入字段，以最后接受的同字段修改为准。请求期间的新修改不被旧响应覆盖，revision 防止较旧响应回退已确认值。

同浏览器通过 storage 事件即时同步；打开设置、窗口重新聚焦、联网和登录时重新读取服务器。断网保留显示效果及待提交字段，联网后重试；失败显示待同步并提供重试；服务未提供偏好接口时明确提示更新并重启服务，登录失效时提示重新登录，不将这些状态统一误报为网络失败。恢复默认需确认，只更新 Markdown 偏好。

服务器首次无偏好时，使用条件初始化迁移浏览器旧专注 / 打字机值；已经存在的服务器配置不会被覆盖。旧全局键只消费一次，避免下一个登录账号继承，后续所有缓存按账号隔离。

## 验证入口

Go 测试位于 `internal/account/`；浏览器测试位于 `web/e2e/account.spec.ts` 和 `account-preferences.spec.ts`。测试使用独立临时数据目录，覆盖资料及头像失败恢复、备份恢复、密码与已连接会话撤销、偏好同步与离线恢复、viewer 隔离、桌面和 390px 手机布局，以及编辑器实例和内容保持。
