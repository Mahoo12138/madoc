# Workspace 搜索

## 服务端契约

`GET /api/workspaces/{workspaceId}/search?q=关键词&limit=30`

- 必须登录并是当前 Workspace 的成员，viewer 可读。成员校验、缓存水位和结果在同一只读事务中读取。
- q 去除首尾空白后为 1–128 个 Unicode 字符，不允许 NUL。limit 为 1–100，默认 30；非法参数返回 400。
- 搜索活动 Item 标题、从根目录开始的完整路径，以及 Markdown 派生缓存正文。白板只检索标题 / 路径，不检索元素文本。
- 查询为字面子串，支持中文 1–2 字和混合标识符。正文同时检索缓存源码和去除 Markdown 标点转义的派生文本，因此 `snake\_case` 可以用 `snake_case` 找到；原始反斜杠查询仍匹配源码。此归一化不是完整 Markdown 纯文本解析，不跨越格式标记拼接词语。英文 ASCII 大小写不敏感；不提供语言分词、词干、拼音或 Unicode 大小写折叠。`%`、`_`、引号和 FTS 运算符不作为特殊语法。
- 服务端先限制 Workspace 和活动层级，再匹配结果。不返回删除项、已删除祖先下的条目或其他工作区候选。
- 排序依次为完整标题、标题包含、路径包含、正文包含；同级按路径和 ID 稳定排序。返回最多 limit 项，`hasMore` 提示需缩小关键词，无无限量返回。

响应包含 `items`、`hasMore` 和 `staleDocuments`。每个结果有 `id`、`type`、`title`、
`path`、`match`（title/path/body）、`snippet`、`cacheSeq`、`headSeq`、`generation`。
正文命中片段最多 160 个字符，从首次命中前最多 48 个字符开始；这是纯文本 Markdown
片段（转义归一化命中时使用对应派生片段），前端不得作为 HTML 注入。正文未命中时片段为空。

## 正文时效

搜索读取 `markdown_cache`，不解析 Yjs，也不另建可能漂移的正文副本。`cacheSeq` 是被检索
缓存的水位，`headSeq` 是快照水位与未压缩更新最大序号的较大值。压缩和内容代际替换
沿用既有状态事务，因此无需另行重建索引。

`staleDocuments` 统计当前工作区中缓存落后于正文的活动文档数，独立于命中结果计算。
即使结果为空，界面也必须提示“部分文档最新修改尚未纳入正文检索”，不能声称已检索
全部最新内容。未发送到服务器的本地修改不在搜索范围。缓存赶上后重新搜索即可看到。
重命名 / 移动 / 删除 / 恢复直接改变同一查询的数据，不维护独立的 stale metadata。

## 实现和边界

第一版使用 SQLite `instr` 字面子串查询与绑定参数，目录路径通过递归 CTE 构建。进程注册确定性的 `madoc_search_text` 函数，仅生成查询用的转义归一化文本，不改写保存内容。复用现有
Workspace/parent 和 Markdown update 索引，不新增数据库迁移、后台任务或外部搜索服务。
这是可验证的功能基线，不宣称在大语料下具有全文索引的性能。FTS 或其他加速应在测量
实际语料后加入，并继续保留短词语义、权限过滤和水位提示。

## 快速打开与搜索界面

桌面侧栏、移动端工具栏和 Ctrl/Cmd+K 打开当前 Workspace 搜索。已有其他弹窗时不抢占
其快捷键；Escape 关闭，方向键选择，Enter 打开。空输入按路径展示最多 30 个活动条目，
文件夹结果展开目录层级，文档 / 白板通过稳定 Item ID 导航，沿用编辑器离开保护。

非空输入去抖 200ms 后调用服务端；输入法组合期间不提交搜索或触发 Enter 打开。
请求绑定关键词和 Workspace，取消过期请求，切换关键词时不展示上一组结果。结果以
纯文本显示类型、标题、路径与正文片段，提供错误重试、数量上限提示、空状态和手动刷新。
缓存落后时同时展示工作区提示与对应条目的提示；正文结果基于查询时的已保存内容，
本地未同步修改不参与检索。目录 metadata 通知使打开的搜索结果失效重取。

搜索、回收站和设置使用独立 React key，避免同级弹窗在导航时错误复用。快捷打开离开
Markdown 时先移除协作插件绑定，再销毁 awareness / Y.Doc 与编辑器，避免延迟事务
访问已销毁的 Milkdown 上下文。

## 验证

`internal/core/search_test.go` 覆盖中文短词、英文大小写、混合标识符、SQL 字面符号、路径、
数量限制、viewer / 非成员 / 跨工作区、重命名 / 移动 / 删除 / 恢复 / 撤权，以及空结果
缓存落后提示、缓存更新、compaction 后水位和代际重置。
`web/e2e/search-api.spec.ts` 验证真实 HTTP 的中文正文、路径 / 片段水位、非法参数、未登录
拒绝及删除 / 恢复检索变化。

`web/e2e/search-ui.spec.ts` 覆盖桌面 / 390px、快捷键、焦点、中文正文、键盘打开与关闭、
远端删除刷新、文件夹展开、缓存滞后提示、重试、HTML 字面显示、IME 和延迟响应隔离，
并检查文档切换无页面异常。
