# Madoc v0.1.0-alpha.1

这是 Madoc 的首个 alpha 发布，面向个人、家庭与小团队的早期试用。Madoc 将协同 Markdown 文档和 Excalidraw 白板放入同一个工作区，以 Go 单二进制、SQLite 和本地附件目录部署，无需 PostgreSQL、Redis 或对象存储服务。

## 本次功能

- 工作区、树形目录、成员邀请及所有者 / 编辑者 / 查看者权限；工作区介绍、成员管理和活动记录。
- Milkdown / Crepe 所见即所得 Markdown，支持多人实时同步、远程光标、图片、表格、代码块与公式；大纲、查找替换、阅读 / 打印、账号编辑偏好及源码查看。
- Excalidraw 白板多人协作、自动保存、在线状态与指针；项目样式的状态工具栏、画布主题 / 背景、查找、帮助、可撤销清空，以及 PNG / SVG / JSON 导出。
- 当前工作区搜索、个人收藏和最近访问；Item / 目录回收站、位置选择恢复及名称确认彻底删除。
- `.md`、`.excalidraw` 与可移植 ZIP 导入；单项、目录和工作区带附件导出，大包分组导出与整组原子导入。
- Markdown / 白板自动与手动版本历史、预览及恢复为新副本；所有者可将手动版本发布为单项固定只读分享。
- 整篇内容评论与工作区活动摘要；本地待提交草稿恢复、准确保存确认、重连重试，以及停服备份 / 验证 / 可回滚恢复维护命令。

## 安装

镜像：`ghcr.io/mahoo12138/madoc:v0.1.0-alpha.1`，目标架构为 `linux/amd64` 与 `linux/arm64`。

```sh
docker pull ghcr.io/mahoo12138/madoc:v0.1.0-alpha.1
docker run -d \
  --name madoc \
  --restart unless-stopped \
  -p 127.0.0.1:3000:3000 \
  -v madoc-data:/data \
  ghcr.io/mahoo12138/madoc:v0.1.0-alpha.1
```

此命令供同一主机上的 HTTPS 反向代理接入。Madoc 自身提供 HTTP，生产 Cookie 带 `Secure` 标记；浏览器必须通过 HTTPS 使用，代理同时转发页面、`/api` 和支持 WebSocket Upgrade 的 `/ws`。不要在生产环境启用 `MADOC_DEV=true`。

首次打开 HTTPS 站点时创建管理员，填写姓名、邮箱和至少 8 个字符的密码；没有默认凭据。初始化完成后使用邮箱和密码登录。`/healthz` 是健康检查入口。

`/data` 持久卷保存 `madoc.db`、`assets/` 与 `server.secret`。服务密钥权限为 `0600`，应与数据库、附件一起保留；重建容器需继续挂载原卷。Release 同时提供 Linux / macOS 的 amd64 / arm64 单二进制压缩包、SHA256 校验清单和镜像摘要。二进制已经嵌入前端，默认数据目录为 `./data`，可通过 `MADOC_DATA` 指定，详见 [构建与部署](https://github.com/Mahoo12138/madoc/blob/v0.1.0-alpha.1/BUILD.md)。

## 备份与升级

升级前让协作者确认已保存、关闭旧编辑页，并下载仍需保留的未同步副本。停止服务后，用当前版本执行 `madoc maintenance backup`，再将生成的完整备份复制到数据卷之外。不要仅复制活跃 WAL 数据库的主 `.db` 文件。

替换为目标版本后继续使用原数据卷；服务与内嵌前端一起升级。启动后检查健康接口、登录、原工作区、文档图片与白板，再重新打开页面。启动时应用增量迁移；回退应停服、恢复升级前完整备份，并使用对应旧版本，不能让旧二进制直接访问升级后的数据库。

恢复到独立空目录前，先用目标数据目录启动一次服务并在健康后停服，无需创建管理员，再执行 `madoc maintenance restore /path/to/backup-directory --confirm`。恢复会先保留当前数据，失败时回滚。旧 AFFiNE / BlockSuite 数据不自动转换，也不自动删除，详见 [迁移说明](https://github.com/Mahoo12138/madoc/blob/v0.1.0-alpha.1/docs/MIGRATION.md)。完整命令见 [备份步骤](https://github.com/Mahoo12138/madoc/blob/v0.1.0-alpha.1/BUILD.md#backup)。

## 已知限制

- alpha 面向单实例、小团队；不提供横向扩容或跨实例实时广播。尚未建立可承诺的容量 / 性能上限。
- 本地恢复依赖当前浏览器保留的站点数据；清除站点数据会删除本地副本。整站离线启动尚未提供，本地草稿不能替代完整备份。
- 历史恢复创建新副本，不覆盖原 Item。自动版本有保留与容量规则；手动版本永久保留，历史用量可超过自动建版的软限制。
- Workspace 删除仍永久；Item / 目录普通删除进入回收站。重要数据应保留独立备份。
- 只读分享固定单项手动版本，不提供公开目录或完整发布站点；已经被访客读取 / 下载的副本无法收回。旧版本若缺少精确附件清单，需重存手动版本再分享图片。
- 评论绑定整篇内容，暂不支持段落锚点、回复或提醒。
- 当前浏览器回归以 Chromium 为主；Safari、Firefox 和真实移动设备尚未完整验收。构建仍保留按需加载大 chunk 提示。

发布验收必须绑定实际发布提交。完整检查顺序和历史验收记录见 [发布检查](https://github.com/Mahoo12138/madoc/blob/v0.1.0-alpha.1/docs/RELEASE.md)，此前记录不能替代本次目标提交的结果。
