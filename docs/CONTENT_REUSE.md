# 内容链接与复用

## 稳定内容链接

文档与白板的文件树操作菜单提供「复制链接」，桌面、手机和 viewer 均可使用。
链接格式为当前站点下的 `/workspace/{workspaceId}/{itemId}`，不包含标题或目录路径。
同工作区改名和移动不改变目标，软删除后拒绝打开，恢复后原链接重新有效。
普通 Markdown 链接和白板链接均可使用这个地址；不引入专有双链语法。

链接只标识内容，不授予访问权，也不生成公开分享凭证。接收者仍须登录且属于目标
工作区。权限撤销后旧链接无效。首次打开不存在 / 不可访问条目显示提示；已打开的
编辑器继续沿用本地只读救援流程。明确收到撤权事件时，不让 REST 重试加载遮住提示。Workspace / 目录读取对
401、403、404 不自动重试，网络和服务器暂时失败仍保留重试。查询失败后子组件
挂载不自动重新请求，避免隐藏搜索面板与页面加载状态交替触发请求循环。

浏览器允许剪贴板时直接复制并显示成功反馈；不支持或拒绝时显示只读链接输入框，
自动选中以便手动复制。不降级为公开链接，不修改内容或权限。文件夹仍通过目录树
展开；这一部分的复制入口只覆盖文档和白板。

## 单项复制 API

`POST /api/items/{itemId}/duplicate`，请求 `{"title":"副本名称"}`，成功返回 201 和新 Item。
要求会话、CSRF 以及原工作区 owner/editor 权限；viewer、非成员、已删除 Item 和文件夹
拒绝复制。title 去除首尾空白后不能为空。同名标题合法，新 UUID 保证内容独立；
新条目追加到原目录末尾，不覆盖现有条目。当前 API 不跨工作区复制。

权限、原条目活动状态、原父目录有效性、内容读取与新条目创建在同一事务；任何错误
整体回滚。成功提交后广播目录失效。不复制收藏、最近访问或来源用户的重试凭证。
每次成功调用产生一份新副本；客户端不可无提示地自动重试不确定的成功请求。

Markdown 原样复制 Yjs 快照和快照之后的增量，不在 Go 解析 Yjs，也不从 Markdown
重新生成正文。新 Item 从 generation 0、snapshot sequence 0 起步，增量分配新的服务端
sequence 和重试 ID；缓存水位映射到副本最新 sequence。源缓存未追上源正文时返回
409 `COPY_NOT_READY`，不留下条目。复制已压缩的文档同样保留完整快照。
白板原样复制完整 scene（包括 files），副本 revision 从 0 开始。

只捕获事务时服务端已保存内容，本地未发送编辑不在范围。后续界面须在当前内容复制
前完成本地保存确认，并明确处理正文投影尚未就绪。工作区附件链接沿用原地址，不搬移
文件、不更改原 item_id；现有删除与彻底删除流程不会自动删除这些共享资源。附件显式
删除仍是原有独立操作，本部分不提供历史资产保护或垃圾回收。

此部分没有 schema 迁移。

## 复制界面与保存确认

文档 / 白板菜单提供「复制内容」，owner/editor 可用，viewer 无入口。默认名称为
「原标题 副本」，可修改；成功后可打开副本，手机同时关闭导航抽屉。提交期间阻止
重复提交与关闭弹窗，失败保留名称及原内容。成功状态不会重复发送创建请求。

当前编辑器通过可释放的保存入口确认本地内容。Markdown 复用现有导出水位检查，
等待本地 ACK 并要求服务器投影达到选定水位；白板等待初始化完成、在线 join 和
完整场景 ACK。确认超时 8 秒则不提交复制 API；离线、已停止保存或尚未初始化时
显示可重试错误。不是当前打开的条目，明确使用服务器已保存版本。

API 请求不自动重试；请求超时或网络错误导致结果无法确认时，提示先检查目录再
决定是否重试。其他窗口未同步的内容不在副本范围。保存入口随编辑器卸载释放，
切换 Item 不复用旧会话。复制过程中远端继续编辑时，由服务端事务捕获当时完整状态。


## 轻量模板

新建文档对话框提供空白、技术设计和会议纪要，非空模板显示只读 Markdown 预览。
模板创建后就是普通文档，不保留专有模板类型或依赖；复用自己的已有文档使用「复制内容」。
不引入模板 DSL、市场或独立模板编辑器。

非空模板在浏览器按需加载 Milkdown / Crepe，解析后生成 `prosemirror` Yjs 快照；
临时编辑器不加入协作房间、不写现有文档，生成后销毁。创建接口接受可选
`initialMarkdown: {snapshot: base64, markdown: string}`，仅 Markdown 类型允许且
快照不能为空。复用既有 2 MiB JSON 解码上限、会话 / CSRF、工作区写权限及父目录验证。
Go 仍把 Yjs 当作不透明数据，不解析 ProseMirror。

新 Item、完整快照和对应正文投影在同一事务创建，初始 generation / sequence 为 0。
多客户端首次打开会绑定同一已有快照，不分别将模板文本插入空 Y.Doc。任何存储失败
回滚条目及正文。无迁移，无旧文档重置，不覆盖同名内容。

空名称不可提交；创建期间禁止重复点击，失败保留名称和模板选择。请求结果不确定
时提醒检查目录后再重试；成功后导航失败只重试打开已创建文档，不重复创建。
手机成功后同时关闭导航抽屉。viewer 不显示新建入口，服务端继续独立拒绝写入。

## 只读源码

Markdown 工具栏提供源码窗口，owner/editor/viewer 都可使用。读取当前 Milkdown
序列化结果，不调用 reset 或替换事务，不增加第二种全文编辑模式。打开时捕获本地
正文快照，远端变化不打断选区，显式「刷新源码」再读取最新内容。

复制和「下载所示源码」使用窗口内完全相同的文本；下载名为 `原标题-源码.md`。
未同步、离线或保存停止时显示本地副本提示。这与工具栏的「导出 Markdown」不同：
后者仍执行 ACK 和服务器投影水位确认。源码窗口不会以本地快照冒充服务器已确认版本。

剪贴板失败时自动选中只读文本并提示手动复制；读取尚未准备完成时显示错误，可刷新
重试。手机使用全屏窗口，源码区域可滚动，关闭后返回原编辑器，不重建协作会话。

## 后续部分

复制单个文档 / 白板、轻量模板、只读源码和文内查找 / 替换已接入。查找限定当前文档，按
区分大小写的字面文本匹配；一个段落内相邻的格式文本可以合并匹配，段落边界和图片等
内联节点会截断匹配。上一个 / 下一个定位匹配文本；替换与全部替换通过 ProseMirror
事务写入共享文档，全部替换作为一次协作撤销操作。viewer 可以查找但不能替换。

## 阅读视图与打印

Markdown 阅读视图继续使用同一 Milkdown / Crepe 文档和样式，切换为只读并隐藏编辑控件；
左侧文件 / 大纲导航继续工作。owner / editor 可随时返回编辑，viewer 默认使用阅读视图。
打印入口从阅读视图提供，以当前页面内容调用浏览器打印；打印样式只保留文档标题和正文，
并处理代码换行、图片宽度及标题、代码块、表格、引用和图片的分页断开。

## 单项固定内容捕获

`GET /api/items/{itemId}/capture` 在一个 SQLite 只读事务中返回单个文档或白板的 Item 元数据
与已保存内容。Markdown 捕获包含 Yjs snapshot、snapshot 之后的有序 updates、generation、
headSeq，以及带 cacheSeq 的 Markdown 派生投影；投影落后时调用方可比较水位并等待或从
Yjs 状态重建，不应把旧投影标成最新。白板捕获包含完整 scene 与 revision。viewer 可读，
非成员、已删除内容和 folder 会被拒绝。响应不缓存。

这是按需返回给授权客户端的值，不写入永久历史，也不代表多个 Item 的共同时间点；捕获完成
后 compaction 不会改变已返回的序列化内容。附件引用仍由内容引擎识别，Go 不解析 Yjs、
Markdown 或 Excalidraw 内部结构。后续目录导出可为每个 Item 分别固定捕获，并在 manifest
记录各自水位与时间；不得宣称整个目录或 Workspace 是原子快照。

文件夹带附件迁出逐项固定捕获、水位和资源映射；不能直接以可能滞后的 Markdown cache
创建导出包。版本历史在阶段 3 将复用同一捕获数据，并另行确定持久化、容量和清理策略。

## 单篇 Markdown 可移植导出

工具栏另提供 Markdown 与附件 ZIP 导出。客户端先等待本地更新 ACK，再请求达到
generation / 最低 seq 的服务器 Markdown 投影；manifest 记录响应对应的实际水位和导出时间。
同一份 Markdown 由当前 Milkdown / Crepe schema 解析，只提取图片节点中的资源引用。
同源 `/api/assets/{UUID}` 图片会按成员权限读取，写入 `assets/asset-{UUID}.{ext}`，并只改写
Markdown 图片目标；围栏和行内代码中的示例保持原文。任何 Madoc 附件读取失败时不下载 ZIP。

ZIP 根目录含 manifest、以跨平台安全文件名保存的 Markdown 和附件目录。外部、站点相对及
其他非 Madoc 资产图片沿用原地址，并在 manifest `unpackagedImages` 中列出；它们不作为已
迁出的二进制资源。单篇导出不含 Workspace、白板或导入；ZIP 在浏览器中生成，不增加服务端
Markdown / Yjs 解析或常驻服务。单篇导出沿用经投影水位确认的 Markdown；文件夹导出使用
下述逐项固定捕获流程。

## 文件夹与 Workspace 可移植导出

文件夹操作菜单和 Workspace 菜单提供 ZIP 导出，owner / editor 可用。文件夹包保留该目录下的
嵌套结构；Workspace 包在以 Workspace 名称命名的根目录下保留完整目录树。Markdown 保存为
`.md`，白板 scene 包装为 Excalidraw version 2 `.excalidraw` JSON（内嵌文件仍在
scene `files` 内）。同级经跨平台清理后重名的条目添加序号；manifest 记录 Item ID、原标题 / 父级、
包内路径、每项捕获时间，以及 Markdown generation / snapshotSeq / seq / projectionSeq 或
白板 revision。

导出逐个调用固定捕获 API，不是文件夹或 Workspace 同一时刻的原子快照，也不含尚未确认到
服务端的修改。若某 Markdown 派生投影未追上 headSeq，或捕获期间条目名称、类型、父级发生
变化，整个包失败并要求重试。通过当前 Crepe schema 读取图片与链接节点；同工作区且包含在
包中的稳定 Item 链接改为相对路径，同源 Madoc 图片附件按 UUID 去重打包并改写为相对路径。
外部 / 相对图片保持原地址并列入 manifest；同工作区但不在包内的 Item 链接保持原地址并列明。
任一 Madoc 附件读取失败时不生成 ZIP。导出在浏览器完成，没有服务端 Yjs / Markdown 解析或
新 migration。

当前打开编辑器以外的未同步标签页修改无法确认，不会假定已包含；大规模目录的容量上限与
分块下载尚未建立，后续根据实际数据规模验证。

## 单篇 Markdown 导入预览

编辑器的 Markdown 导入入口先显示文件名、可编辑的新文档名称和只读源码预览，再在当前
文件夹创建独立文档；它不重置或覆盖当前 Item。初始快照由浏览器使用和活动文档相同的
Milkdown / Crepe schema 生成，不加入协作房间；服务端在同一事务中创建 Item、Yjs 快照和
正文投影。创建失败时保留名称与预览；创建结果不确定时先检查目录，再由用户决定重试。

此入口只支持 `.md` / `.markdown` 正文，不携带图片二进制；原文中的图片引用保持原样。
附件 ZIP 导入、路径与资源映射、目录结构和冲突预览仍待实现。ZIP 审阅器以流式方式读取并
核对 manifest 与包内内容，检查实际压缩 / 解压字节、单项大小和条目数；拒绝路径穿越、重复路径及文件 / 目录冲突，
在完整验证前不创建 Item 或附件。具体限额和多项创建失败后的处理规则确定后，才接入写入流程。
客户端仍以实际序列化请求体检查现有 2 MiB JSON 解码上限，超限时在创建前给出拆分提示。

## Excalidraw 白板导入预览

白板导出菜单提供 `.excalidraw` JSON 导入。客户端检查文件大小及 Excalidraw version 2
结构，预览元素数、嵌入文件数和可编辑的新白板名称；确认后在当前文件夹创建独立白板，
保留 elements、appState 与 files（包括嵌入图片），不修改当前白板。服务端在同一事务中
创建 Item 和初始 scene，revision 从 0 开始；viewer 不显示导入入口，REST / core 仍执行
写权限检查。单文件与实际请求体均受 2 MiB JSON 上限约束，超限或结构 / 版本无效时不会
创建条目。创建响应不确定时提示先检查目录；已创建但导航失败时只重试打开，不重复创建。

此入口不实现导入到现有白板、目录包或额外的资产上传；保真范围是 Excalidraw 文件内
的场景数据与嵌入文件。

## 验证

`markdown-find-replace.spec.ts` 验证区分大小写、中文文本、跨格式边界、远端协作修改后
结果刷新、单项 / 全部替换、批量单步撤销，以及 viewer 只读。

`markdown-reading-view.spec.ts` 验证只读呈现沿用原文档 / 大纲、返回编辑、viewer 默认阅读，
以及打印时只显示内容区并应用分页规则。

`markdown-portable-export.spec.ts` 验证 ZIP 内真实附件字节、相对路径改写、manifest 实际
generation / seq 与导出时间、外部图片清单、代码示例 URL 不改写，以及附件缺失时拒绝生成
不完整的 ZIP。

`markdown-import-preview.spec.ts` 验证只读预览、文件名转新标题、模板 schema 的加粗 / 脚注
保真、默认新建且源文档不变，以及服务失败后保留名称和正文供重试。模板创建回归继续验证
同一快照编译流程不会改变现有模板行为。

`item-links.spec.ts` 验证桌面与 390px 手机剪贴板内容、改名 / 移动后的原地址、白板
打开、删除与恢复、viewer 手动复制及撤权后的内容拒绝。已有 workspace-live 测试
继续验证打开中被删除 / 降权后的救援内容保留。


`initial_markdown_test.go` 覆盖初始快照、序号、父目录、权限、错误类型 / 空快照和事务
失败回滚。`document-templates.spec.ts` 验证两种模板的实际 Yjs 快照、双标签编辑与刷新、
手机失败重试和抽屉关闭；空白创建沿用独立 MVP 核心流程验证。

`markdown-source.spec.ts` 验证桌面 / 手机只读、剪贴板与下载文本完全一致、转义和代码
源码、远端更新后显式刷新、手动复制回退、未同步提示与 viewer 不发送正文更新。

`excalidraw-import-preview.spec.ts` 验证 version 2 结构预览、嵌入文件保留、在当前目录
创建不同于源条目的新白板、原白板不变，以及不支持版本时不创建内容；`initial_whiteboard_test.go`
覆盖场景初始 revision、嵌入文件、viewer 拒绝、父目录验证及创建事务失败回滚。

`capture_test.go` 验证单项捕获的 Markdown generation / cacheSeq / headSeq、Yjs updates 在
compaction 后仍作为返回值保持不变、白板 revision / scene 和 viewer 读取权限；
`item-capture.spec.ts` 验证 REST 响应的 Markdown / 白板内容形状及 no-store 缓存头。

`folder-portable-export.spec.ts` 验证嵌套结构、同名路径消歧、逐项 manifest 水位、Excalidraw
version 2 JSON 导出后通过既有导入预览往返、Markdown 附件字节与内部 Item 链接映射、代码围栏
示例保留；缺失附件时拒绝生成 ZIP。
