# 内容链接与复用

## 稳定内容链接

文档与白板的文件树操作菜单提供「复制链接」，桌面、手机和 viewer 均可使用。
链接格式为当前站点下的 `/workspace/{workspaceId}/{itemId}`，不包含标题或目录路径。
同工作区改名和移动不改变目标，软删除后拒绝打开，恢复后原链接重新有效。
普通 Markdown 链接和白板链接均可使用这个地址；不引入专有双链语法。

链接只标识内容，不授予访问权，也不生成公开分享凭证。接收者仍须登录且属于目标
工作区。权限撤销后旧链接无效。首次打开不存在 / 不可访问条目显示提示；已打开的
编辑器继续沿用本地只读救援流程。明确收到撤权事件时，不让 REST 重试加载遮住提示。Workspace / 目录读取对
401、403、404 不自动重试，网络和服务器暂时失败仍保留重试。查询失败后子组件
挂载不自动重新请求，避免隐藏搜索面板与页面加载状态交替触发请求循环。

浏览器允许剪贴板时直接复制并显示成功反馈；不支持或拒绝时显示只读链接输入框，
自动选中以便手动复制。不降级为公开链接，不修改内容或权限。文件夹仍通过目录树
展开；这一部分的复制入口只覆盖文档和白板。

## 单项复制 API

`POST /api/items/{itemId}/duplicate`，请求 `{"title":"副本名称"}`，成功返回 201 和新 Item。
要求会话、CSRF 以及原工作区 owner/editor 权限；viewer、非成员、已删除 Item 和文件夹
拒绝复制。title 去除首尾空白后不能为空。同名标题合法，新 UUID 保证内容独立；
新条目追加到原目录末尾，不覆盖现有条目。当前 API 不跨工作区复制。

权限、原条目活动状态、原父目录有效性、内容读取与新条目创建在同一事务；任何错误
整体回滚。成功提交后广播目录失效。不复制收藏、最近访问或来源用户的重试凭证。
每次成功调用产生一份新副本；客户端不可无提示地自动重试不确定的成功请求。

Markdown 原样复制 Yjs 快照和快照之后的增量，不在 Go 解析 Yjs，也不从 Markdown
重新生成正文。新 Item 从 generation 0、snapshot sequence 0 起步，增量分配新的服务端
sequence 和重试 ID；缓存水位映射到副本最新 sequence。源缓存未追上源正文时返回
409 `COPY_NOT_READY`，不留下条目。复制已压缩的文档同样保留完整快照。
白板原样复制完整 scene（包括 files），副本 revision 从 0 开始。

只捕获事务时服务端已保存内容，本地未发送编辑不在范围。后续界面须在当前内容复制
前完成本地保存确认，并明确处理正文投影尚未就绪。工作区附件链接沿用原地址，不搬移
文件、不更改原 item_id；现有删除与彻底删除流程不会自动删除这些共享资源。附件显式
删除仍是原有独立操作，本部分不提供历史资产保护或垃圾回收。

此部分没有 schema 迁移。

## 复制界面与保存确认

文档 / 白板菜单提供「复制内容」，owner/editor 可用，viewer 无入口。默认名称为
「原标题 副本」，可修改；成功后可打开副本，手机同时关闭导航抽屉。提交期间阻止
重复提交与关闭弹窗，失败保留名称及原内容。成功状态不会重复发送创建请求。

当前编辑器通过可释放的保存入口确认本地内容。Markdown 复用现有导出水位检查，
等待本地 ACK 并要求服务器投影达到选定水位；白板等待初始化完成、在线 join 和
完整场景 ACK。确认超时 8 秒则不提交复制 API；离线、已停止保存或尚未初始化时
显示可重试错误。不是当前打开的条目，明确使用服务器已保存版本。

API 请求不自动重试；请求超时或网络错误导致结果无法确认时，提示先检查目录再
决定是否重试。其他窗口未同步的内容不在副本范围。保存入口随编辑器卸载释放，
切换 Item 不复用旧会话。复制过程中远端继续编辑时，由服务端事务捕获当时完整状态。


## 轻量模板

新建文档对话框提供空白、技术设计和会议纪要，非空模板显示只读 Markdown 预览。
模板创建后就是普通文档，不保留专有模板类型或依赖；复用自己的已有文档使用「复制内容」。
不引入模板 DSL、市场或独立模板编辑器。

非空模板在浏览器按需加载 Milkdown / Crepe，解析后生成 `prosemirror` Yjs 快照；
临时编辑器不加入协作房间、不写现有文档，生成后销毁。创建接口接受可选
`initialMarkdown: {snapshot: base64, markdown: string}`，仅 Markdown 类型允许且
快照不能为空。复用既有 2 MiB JSON 解码上限、会话 / CSRF、工作区写权限及父目录验证。
Go 仍把 Yjs 当作不透明数据，不解析 ProseMirror。

新 Item、完整快照和对应正文投影在同一事务创建，初始 generation / sequence 为 0。
多客户端首次打开会绑定同一已有快照，不分别将模板文本插入空 Y.Doc。任何存储失败
回滚条目及正文。无迁移，无旧文档重置，不覆盖同名内容。

空名称不可提交；创建期间禁止重复点击，失败保留名称和模板选择。请求结果不确定
时提醒检查目录后再重试；成功后导航失败只重试打开已创建文档，不重复创建。
手机成功后同时关闭导航抽屉。viewer 不显示新建入口，服务端继续独立拒绝写入。

## 只读源码

Markdown 工具栏提供源码窗口，owner/editor/viewer 都可使用。读取当前 Milkdown
序列化结果，不调用 reset 或替换事务，不增加第二种全文编辑模式。打开时捕获本地
正文快照，远端变化不打断选区，显式「刷新源码」再读取最新内容。

复制和「下载所示源码」使用窗口内完全相同的文本；下载名为 `原标题-源码.md`。
未同步、离线或保存停止时显示本地副本提示。这与工具栏的「导出 Markdown」不同：
后者仍执行 ACK 和服务器投影水位确认。源码窗口不会以本地快照冒充服务器已确认版本。

剪贴板失败时自动选中只读文本并提示手动复制；读取尚未准备完成时显示错误，可刷新
重试。手机使用全屏窗口，源码区域可滚动，关闭后返回原编辑器，不重建协作会话。
